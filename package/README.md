# @olishiz/connection-monitor

GitHub Packages listing for the **native macOS app**.

This is **not** a Node.js library. Do not `require()` it in JS projects.

## Install the Mac app

### Homebrew

```bash
brew tap olishiz/tap
brew trust olishiz/tap
brew install --cask connection-monitor
```

### Download

[Releases](https://github.com/olishiz/connection-monitor/releases) — use the `.dmg`.

### Source

```bash
git clone https://github.com/olishiz/connection-monitor.git
open connection-monitor/ConnectionMonitor.xcodeproj
```
